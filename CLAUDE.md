# build-explainer-skill

This folder is the `/build-explainer` Claude Code skill. If the user asked you to "set this up" / install it, open
`README.md` and follow the section **"## Instructions for Claude (setup)"** exactly (clone to `~/.claude/skills/build-explainer`,
run `python setup/install.py`, ask before installing Blender/ffmpeg, read the PASS/FAIL table, tell the user to restart Claude Code).

Paths for the scripts live in `config.json` (written by the installer, git-ignored). Skill behaviour is in `SKILL.md`.
